# Repository agent instructions

When asked to review, diagnose, or recommend changes for organic search performance,
use the `venetia-seo` MCP tools before reading generated Markdown reports. Start with
`get_data_quality` and `get_seo_overview`, then use the page, query, SERP, engagement,
and change-timeline tools needed to test possible explanations. Treat temporal
correlation as evidence, not proof. Do not modify site content unless the user
explicitly requests implementation.
